Deploy Guide

Put your project online, for free

THANU AI doesn't run its own hosting service — instead, here's a real, working path to get your site live using the same free platforms professionals use.

Why not "one-click deploy from THANU AI"? A real hosting service costs money to run (servers, bandwidth, storage) and comes with real responsibility for what gets uploaded to it. Rather than promise something that isn't actually built, this guide points you straight to platforms that already do it well — for free.
1

Pick a platform

For a static site like this one, Netlify or Vercel are the easiest — both have generous free tiers and no credit card required to start.

2

Sign up

Create an account with your email or GitHub. If you're under 18, check the platform's terms — some require a parent/guardian for account creation.

3

Upload your project

Drag and drop your public folder (the one with index.html) straight into the Netlify/Vercel dashboard. No command line needed for a basic static deploy.

4

Go live

You'll get a free yourproject.netlify.app or yourproject.vercel.app link instantly. You can connect a custom domain later if you buy one.

5

Need the AI chat working too?

Since app.html calls a server (index.js) for real AI replies, a static host like Netlify won't run that part. Use Render or Railway instead — both can run the full Node project and let you set your GEMINI_API_KEY or ANTHROPIC_API_KEY safely as an environment variable.
